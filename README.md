# Arduino PID Motor Speed Control

Система автоматического регулирования скорости электродвигателя на базе Arduino с ПИД-регулятором и C# WinForms-приложением для мониторинга параметров в реальном времени.

Проект реализует замкнутую систему управления скоростью двигателя: Arduino измеряет текущую скорость вращения, рассчитывает управляющее воздействие по ПИД-закону и формирует PWM-сигнал. C# приложение принимает телеметрию по COM-порту, отображает текущие параметры и строит графики переходного процесса.


## Назначение проекта

Цель проекта — разработка программно-аппаратного комплекса для управления скоростью электродвигателя с обратной связью.

Проект может использоваться для:

- изучения принципов ПИД-регулирования;
- анализа переходных процессов электропривода;
- настройки коэффициентов P, I, D;
- визуализации уставки, фактической скорости и управляющего воздействия;
- демонстрации работы замкнутой системы автоматического регулирования.


## Общий принцип работы

1. Пользователь задаёт требуемую скорость вращения с помощью потенциометра.
2. Arduino считывает сигнал с датчика оборотов.
3. Программа рассчитывает текущую скорость двигателя в об/мин.
4. ПИД-регулятор вычисляет управляющее воздействие.
5. PWM-сигнал подаётся на силовой ключ управления двигателем.
6. Arduino отправляет телеметрию в C# приложение.
7. C# приложение отображает значения и строит графики в реальном времени.


## Функциональные возможности

## Формат телеметрии

Arduino отправляет телеметрию в формате:

T,TimeMs,SetpointRpm,MeasuredRpm,PwmPercent

Пример:

T,12500,1500,1420,68


| Поле | Описание |
|---|---|
| T | признак строки телеметрии |
| TimeMs | время работы Arduino, мс |
| SetpointRpm | заданная скорость, об/мин |
| MeasuredRpm | измеренная скорость, об/мин |
| PwmPercent | управляющее воздействие, % |


## Команды от C# приложения к Arduino

| Команда | Назначение |
|---|---|
| GET | запрос текущих коэффициентов ПИД |
| P,value | установка коэффициента Kp |
| I,value | установка коэффициента Ki |
| D,value | установка коэффициента Kd |
| SAVE | сохранение коэффициентов в EEPROM |

Примеры команд:

P,0.25
I,0.80
D,0.00
SAVE


## Ответы Arduino

### Текущая конфигурация ПИД

CFG,Kp,Ki,Kd

Пример:

CFG,0.200000,0.800000,0.000000

### Подтверждение изменения коэффициента

ACK,P,0.250000

### Подтверждение сохранения в EEPROM

ACK,SAVE


## C# приложение

Приложение PID_Regulator предназначено для визуального контроля работы системы регулирования.

Основные формы приложения:

| Форма | Назначение |
|---|---|
| MainForm | основное окно, COM-порт, текущие значения, коэффициенты ПИД |
| GraphicsForm | график уставки, фактической скорости и PWM |
| ErrorGraphForm | график ошибки регулирования |
| PortSelectionNameForm | форма выбора порта |

### Отображаемые параметры

| Параметр | Описание |
|---|---|
| Заданная скорость | значение уставки с потенциометра |
| Фактическая скорость | измеренная скорость двигателя |
| PWM | управляющее воздействие в процентах |
| Ошибка | отклонение фактической скорости от заданной |

## Графики

В приложении предусмотрены графики:

- заданной скорости;
- фактической скорости;
- PWM;
- ошибки регулирования e(t).

На основном графике можно включать и отключать отдельные серии данных. Также реализовано масштабирование и автоматическая прокрутка по времени.


## Требования

### Аппаратные требования

- Arduino Uno/Nano или совместимая плата;
- двигатель постоянного тока или другой двигатель с PWM-управлением через внешний ключ;
- датчик оборотов;
- потенциометр;
- кнопка;
- LCD 16x2 с I2C-интерфейсом;
- внешний источник питания двигателя;
- общий GND между Arduino и силовой частью.


## Запуск C# приложения

1. Открыть решение:

desktop-app/PID_Regulator.sln

2. Собрать проект в Visual Studio.
3. Подключить Arduino к компьютеру.
4. Проверить, что Arduino определяется как COM5.
5. Запустить приложение.
6. После подключения приложение запросит текущие коэффициенты ПИД командой GET.
7. При поступлении телеметрии значения начнут отображаться в окне программы.


## Настройка коэффициентов ПИД

В C# приложении можно изменить коэффициенты:

- P;
- I;
- D.

После отправки коэффициента Arduino возвращает подтверждение. Для сохранения коэффициентов в EEPROM используется отдельная команда SAVE.
