# PID Telemetry Monitor

В этой папке находится C# WinForms-приложение для приёма телеметрии от Arduino и построения графиков.

Приложение выполняет:

- подключение к COM-порту;
- приём данных от Arduino;
- разбор строк телеметрии;
- отображение заданной скорости;
- отображение фактической скорости;
- отображение PWM;
- отображение ошибки регулирования;
- отправку коэффициентов ПИД-регулятора на Arduino.
